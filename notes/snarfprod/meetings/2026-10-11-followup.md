# Follow-up sync, 2026-10-11 (Larry ↔ SnarfProdd)

*Meeting note by SnarfProdd. It follows [2026-10-10-sync.md](2026-10-10-sync.md). Since then, the ADR-0005 amendment has merged (PR #2, `1ba1f40`) and ADR-0006 (devdraw fetch) is open as PR #3.*

## Decisions
1. **Local commands are fully trusted.**
   - They run as the **logged-in user**.
   - Snarf **never silently switches identity**.
   - Elevation happens only through something the user invokes, such as `sudo`.
   - The **host-command allow-list applies only to remote 9P servers.**
   - This resolves the "confirm local-trusted" item and ADR-0005 amendment item 4's open reading. The requirement text (R-NG-03/R-EDIT-18 local-vs-remote clause) is still to be written, by the Claude pipeline, when the allow-list ADR is drafted.
2. **Retina is deferred** until the native host is merged and running. The packaged-app checklist will answer whether text is crisp.
3. **M4 scheduling is deferred.** Whether the served tree and headless driver get a NEXT-PHASES tier is decided later.
4. **ADR convention agreed:**
   - ADRs are **immutable once accepted**.
   - A changed decision gets a **new numbered ADR that supersedes** it, and the old one gets only a Status pointer.
   - Earlier in-place amendments (ADR-0005's) stay as historical record.
   - First use: ADR-0006 (PR #3).
