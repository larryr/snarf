# Product sync, 2026-10-10 (Larry ↔ SnarfProdd)

*Meeting note by SnarfProdd. Also captured from the pipeline side in [`notes/claude/roadmap-review-2026-10-10.md`](../../claude/roadmap-review-2026-10-10.md) (§"Product sync"). The agreed baseline is [`docs/product/`](../../../docs/product/).*

## Decisions
1. **The native host is primary.** Snarf will ship as targeted native binaries built with Zig cross-compile. Reasons:
   - The browser can't reach ACME-level usability (no warp, keys it steals, no real processes).
   - Its only real benefit was no install.
   - Snarf's job is editing documents and running text services, which is heavy local use.
   - Remote work goes through **dedicated headless 9P servers**.
2. **WASM/browser becomes a frozen secondary target.** It must keep building and passing tests. It gets no new browser features and no WASM-VM wrapping. The core stays host-neutral (R-OV-03 and R-OV-09 unchanged).
3. **Trackpad direction:**
   - Use **hold-and-tap chords plus modifier+click**: direction D1 in [`docs/product/research/touchpad-interaction.md`](../../../docs/product/research/touchpad-interaction.md). This is native-only, as a `devdraw` patch.
   - Larry uses macOS three-finger drag, so **3-finger tap is unreliable for him**.
   - **The dual Magic Trackpad (D5) stays parked** unless multitouch adds something a modifier key can't, given the cost of taking both hands off the keyboard.
4. **Where notes live:**
   - SnarfProdd working notes go in `notes/snarfprod/` and are committed to `main` directly.
   - Everything else goes through a PR.
   - `docs/product/` stays the agreed baseline, and proposals are promoted into it by PR.

## Roadmap impact
The detail is in [`roadmap-v0.2-proposal.md`](../roadmap-v0.2-proposal.md).
- **Pointer Lock spike:** leaves M0 and is parked as "only if a browser host returns".
- **`savemouse`/`restoremouse`:** becomes its own small, host-agnostic item with a headless test (Fable, review Finding 4).
- **M1:**
  - The browser Clipboard API is dropped. The system clipboard goes native-first via devdraw `Trdsnarf`/`Twrsnarf`.
  - A native file server is added, so Put/Dump/Load work on native (today they return `NotMounted`).
- **M2:** the command allow-list scope narrows to remote 9P servers (local native is trusted; to be confirmed). A headless 9P server for remote machines is added.
- **M3:** native daily-driver polish, plus the decision between devdraw and a self-drawn window (rhun spike), which is no longer parked.
- **M4:** reframed as specified-but-unscheduled backlog that can be scheduled now. Only `Tauth` plus the external-attach transport is gated on an ADR (Fable, Finding 3).
- **M5:** still stop-and-ask, now for a sharper reason: it adds a new actor class with no requirement, and it brushes against R-NG-04.
