**Notes and observations (not filed):**
- `snarf-native FILE` ignores file arguments: it opens only the `/` window. In ACME, `acme file` opens the file. This was not checked for dev.1 and isn't a regression, but it's worth a PM look.
- B3 on `/dev/draw/` opens an empty directory window. Plan 9 lists `new` and the connection directories there. This is cosmetic.
- The Put was fast in ReleaseSafe, but the temp still appeared about 0 s after B2, and the kill window was wide enough to hit.
- Still open from dev.1: #59 (README for binary users, LICENSE, `--help`/`--version`) and #70 (a cut-off Put of a new file).
