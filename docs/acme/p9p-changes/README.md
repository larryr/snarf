# plan9port `CHANGES` — Russ Cox et al.

The plan9port change log (2003–), including ~60 `acme:` / `acme Mail:` / `libacme`
entries (big tags, multiline tags, Load/Dump fixes, chord fixes, `acme(3)` library).
Useful as a dated record of how plan9port's Acme diverged from the Plan 9 original. It
is a change log, not a paper, and says nothing about Acme's colors.

**Status: supplementary — not definitive.**
